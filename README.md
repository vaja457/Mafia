# 🎭 მაფიის სამაგიდო მოდერატორი (Mafia Moderator Web App)

სრულფასოვანი, მობილურზე ოპტიმიზებული (Mobile-First) ვებ-აპლიკაცია სამაგიდო თამაში „მაფიის“ მოდერაციისთვის.

პლატფორმა შექმნილია ისე, რომ **ჯგუფის ჰოსტიც ჩვეულებრივი მოთამაშეა**. მისი ტელეფონი მართავს აუდიო-გახმოვანებას, ტაიმერებს, როლების ფარულ დარიგებას და კენჭისყრის პროცესს.

---

## ✨ ძირითადი ფუნქციები

1. **📱 Mobile-First & QR მოწვევა:**
   - იხსნება პირდაპირ ბრაუზერში ნებისმიერ ტელეფონზე (iPhone, Android).
   - 6-სიმბოლოიანი ოთახის კოდი, გაზიარებადი ლინკი და QR კოდი.

2. **🔊 Smart Web Audio Engine & Audio Ducking:**
   - მისტიკური ფონური მუსიკა (Noir Ambient Soundscape).
   - **Audio Ducking:** როდესაც ქართულენოვანი ხმა ლაპარაკობს (*„იძინებს ქალაქი“*, *„იღვიძებს მაფია...“*), მუსიკის ხმა ავტომატურად იკლებს, შემდეგ კი ისევ მაღლა იწევს.
   - 1-წუთიანი სიტყვის ტაიმერის რეზონანსული **გონგის (Gong/Bell)** ხმა, გასროლის და დილის ზარების ხმოვანი ეფექტები.
   - სუბტიტრების ფანჯარა ეკრანზე.

3. **🃏 როლების ფარული დარიგება (11+ მოთამაშე):**
   - 3 მაფია (მათ შორის 1 დონი, რომელიც ეძებს დეტექტივს).
   - 1 დეტექტივი / შერიფი (ამოწმებს მაფიას).
   - 1 ექიმი (1-ჯერადი დაჰილვის ლიმიტი თითო მოთამაშეზე მთელ თამაშში).
   - 1 სერიული მკვლელი (მაქსიმუმ 2 მკვლელობა + სვლის გამოტოვება/შენახვა).
   - 5+ პატიოსანი მოქალაქე.

4. **🌙 1-ლი გაცნობითი ღამე და მე-2+ მოქმედების ღამეები:**
   - 1-ლი ღამე: მხოლოდ მაფიის გაცნობა და ტაქტიკის შეთანხმება.
   - მე-2+ ღამე: მაფიის გასროლა $\rightarrow$ დონის შემოწმება $\rightarrow$ დეტექტივის შემოწმება $\rightarrow$ ექიმის დაჰილვა $\rightarrow$ სერიული მკვლელი.
   - მყისიერი ფარული პასუხები დეტექტივსა და დონს საკუთარ ეკრანზე.

5. **☀️ დღის ფაზა, დისკუსიები და კენჭისყრა:**
   - წრის შემთხვევითი გახსნა 1-ლ დღეს, შემდეგ კი წრიულად გადანაცვლება.
   - 1-წუთიანი სპიკერის ტაიმერი პაუზით და შემდეგ მოთამაშეზე გადასვლით.
   - კანდიდატების დასახელება (Nomination) ჰოსტის მიერ.
   - 30-წამიანი დაცვის სიტყვები.
   - **ხმების გაყოფის (Tie-Breaker) ალგორითმი:** 30 წმ დაცვა $\rightarrow$ ხელახალი კენჭისყრა $\rightarrow$ კითხვა: *„გავარდეს თუ არა ორივე მოთამაშე?“* (>50% ორივე ვარდება, $\le$50% ორივე რჩება).

6. **🏆 მოგების ავტომატური გამოთვლა (Win Condition Engine):**
   - ქალაქის გამარჯვება (მაფია & სერიული განადგურებულია).
   - მაფიის გამარჯვება (მაფია $\ge$ მოქალაქეებზე და სერიული მკვლელი მკვდარია).
   - სერიული მკვლელის გამარჯვება (დარჩა 1-1-ზე ნებისმიერ მოთამაშესთან).

## 🚀 გაშვების ინსტრუქცია

### 1. დეველოპმენტ რეჟიმში გაშვება:
```bash
npm run dev
```
* სერვერი ჩაირთვება `http://localhost:3001`-ზე.
* ვებ-ინტერფეისი გაეშვება `http://localhost:5173`-ზე.

### 2. პროდაქშენ რეჟიმში გაშვება (ერთ პორტზე):
```bash
npm run build
npm run start
```
აპლიკაცია გაეშვება `http://localhost:3001`-ზე.

### 3. მობილური ტელეფონებიდან შეერთება (ლოკალურ Wi-Fi ქსელში):
1. დარწმუნდით, რომ კომპიუტერი და ტელეფონები ერთსა და იმავე Wi-Fi ქსელშია.
2. გაიგეთ კომპიუტერის ლოკალური IP მისამართი (მაგ: `192.168.1.15`).
3. ტელეფონებში გახსენით ბრაუზერი და შედით: `http://192.168.1.15:5173` (ან `http://192.168.1.15:3001`).
4. ჰოსტი შექმნის ოთახს და ეკრანზე გამოვა QR კოდი, რომელსაც ყველა მეგობარი დაასკანერებს!
